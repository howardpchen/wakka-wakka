# Launcher icon generation record

Generated with the built-in image-generation tool, then locally chroma-keyed,
cropped, padded, and resized for Pebble.

## Prompt

Use case: logo-brand

Asset type: Pebble smartwatch launcher/menu icon, designed to remain
recognizable at 25×25 pixels.

Create an original compact game icon for Wakka Wakka: a small golden-yellow
comet-like orb with a short angular motion trail moving around a bright cyan
right-angle corridor, followed by four tiny square sparks colored red, cyan,
magenta, and orange.

Use crisp flat pixel-inspired geometry, strong contrast, generous padding, no
text, no watermark, and no copied arcade imagery. Avoid a wedge-mouth circle,
rival silhouettes from existing games, familiar maze layouts, cabinet imagery, and existing game
logos.

The generation source used a flat green chroma-key background, which was
removed locally to produce transparent PNG assets.
