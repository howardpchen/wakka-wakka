# Wakka Wakka privacy statement

Wakka Wakka does not collect, store, transmit, sell, or share personal data.

The game:

- does not require an account;
- does not use analytics or advertising;
- does not access the internet during play;
- does not send data to a phone or remote service;
- does not collect location, health, microphone, contact, or message data.

Accelerometer readings are processed locally on the watch only to control
movement. They are not stored or transmitted.

Game state is session-local in the current release. Uninstalling or closing the
app does not leave personal information on a server because no server is used.
